## Cloudflare route kararı

İlk seçili yüzey yalnız mevcut `etkinlik-api` public DTO sözleşmesidir. Auth, profile, join/save, rooms, matching, messages, reports, account deletion, Realtime ve private Storage Worker/shared cache üzerinden geçirilmez. Worker yanıtı varsayılan `private, no-store`; yalnız doğrulanmış public catalog GET/HEAD adapter rotaları kısa TTL ile cache edilebilir. Mobilde `EDGE_API_BASE_URL` yapılandırılmamışsa mevcut Supabase Function yolu korunur.
